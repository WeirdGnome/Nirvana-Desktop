# Schemes from Redmond97 SE

The colors in this folder come from the presets of the
[Redmond97 SE](https://codeberg.org/Sliver_X/Redmond97-SE) project (Sliver X), based on
[Redmond97](https://github.com/matthewmx86/Redmond97) (matthewmx86). Both projects are
licensed under the GNU GPL 3.0.

The files were generated with `tools/import-redmond97.py` from the `builder/presets/`
folder. Only the colors and scheme names were taken, no graphics, scripts or wallpapers.
