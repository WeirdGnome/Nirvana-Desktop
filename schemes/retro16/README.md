# Nirvana Classic

Six color schemes in the spirit of the 16-bit home computer desktops, from the late 1980s
to the late 2000s. The numbers name the eras, not products; the colors were chosen for
Nirvana Desktop and every gadget is drawn by Nirvana itself. Each scheme also brings the
classic 16-bit window gadgets (`window_style=classic`): close on the left, zoom and depth on
the right, a size gadget in the corner. Choosing the scheme turns on Preferences > Desktop >
Classic 16-bit windows; that switch can be turned off again.

| Scheme | Look |
|---|---|
| Nirvana Classic 1.3 | blue desktop, white bars, orange highlights |
| Nirvana Classic 2.1 | light gray, blue title bars |
| Nirvana Classic 3.1 | eight-color gray, steel blue and beige |
| Nirvana Classic 3.2 | medium gray canvas, cobalt blue title bars, crisp bevels |
| Nirvana Classic 3.9 | gradient bars, warm accent, blue desktop |
| Nirvana NextGen 4.1 | glass bars, deep blue desktop |

Next to them in the main folder: **Nirvana Default** (light gray, blue gradient bars, the
default of a new account), **Slate** (dark graphite and teal) and **Ice & Silver** (light
platinum with icy blue).
