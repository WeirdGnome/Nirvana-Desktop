# Schematy z Redmond97 SE

Kolory w tym katalogu pochodzą z presetów projektu
[Redmond97 SE](https://codeberg.org/Sliver_X/Redmond97-SE) (Sliver X), opartego na
[Redmond97](https://github.com/matthewmx86/Redmond97) (matthewmx86). Oba projekty są
na licencji GNU GPL 3.0.

Pliki wygenerowano skryptem `tools/importuj-redmond97.py` z katalogu
`builder/presets/`. Wzięto tylko kolory i nazwy schematów, bez grafik, skryptów i tapet.
